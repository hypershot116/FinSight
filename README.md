# FinSight - AI-Powered Financial Dashboard

A secure, full-stack financial tracking application featuring AI-driven insights, role-based access control, and complete transaction management. 

## Tech Stack
* **Frontend:** React, TypeScript, Tailwind CSS, Recharts, Vite
* **Backend:** FastAPI, Python, SQLAlchemy, JWT Authentication, bcrypt
* **Database:** PostgreSQL (Neon Serverless)
* **AI Integration:** Google Gemini 2.5 Flash

## Features
* **Secure Authentication:** JWT-based auth with email OTP verification and password recovery.
* **Role-Based Access:** Isolated System Admin portal for user management.
* **Transaction Engine:** Full CRUD operations for income and expenses with automatic KPI calculations.
* **Interactive Analytics:** Dynamic Area and Pie charts reflecting real-time cash flow.
* **AI Analyst:** Context-aware financial insights generated directly from user transaction history.
